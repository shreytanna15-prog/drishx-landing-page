# DrishX Landing Page Workspace Instructions

## Project Context
This is the dedicated marketing landing page for **DrishX** (B2B Optical Lens Wholesale Platform).
- Stack: Next.js (App Router), React 19, Tailwind CSS v4, shadcn/ui.
- Monorepo: Turborepo workspace (`apps/web` contains the Next.js app, `packages/ui` contains shadcn components).

## Design System & Brand Identity
Follow [DESIGN.md](file:///c:/app-project/drishx/drishx-landing-page/DESIGN.md) strictly:
- **Brand name:** Always **DrishX** (never OptixFi or invented names).
- **Primary Color:** Amber `#F0A132` (hover: `#E8941F`).
- **Surfaces (Dark Mode Primary):** Background `#0B0F14`, elevated `#0F1620`, text `#EAF0FA`, muted `#AAB2C0`.
- **Primary Button Rule:** Text on amber is ALWAYS dark ink (`#0B0F14`), NEVER white text on amber.
- **Typography:** Cormorant Garamond (display/hero), Geist (sans/body).
